# EM-006：加寬矩陣及同步上方水平捲動條

日期：2026-10-02。實作、啟用與 GitHub 備份：既有 Luna 6.0 Max 工作視窗。PM 負責工單與獨立驗收，不修改應用程式。

## 使用者需求

「矩陣視窗做寬一點，然後上面也要有可移動的 bar。」

沿用既有逐月矩陣；bar 指水平捲動條。使用現有 CSS、瀏覽器原生捲動及少量 JavaScript，不增加依賴或替換表格。

## 實作目標與驗收

1. **加寬矩陣頁**：矩陣使用可用視窗寬度，桌面兩側主區域各約 24px，取消此頁的固定最大寬度，減少矩陣面板內多餘空白。既有輸入、逐筆修正及其他明細頁保持原本版面。以 1440px、1920px 與窄視窗核對；窄視窗只在矩陣容器水平捲動，整頁不可向右溢出。
2. **上方捲動條**：在矩陣表格上方新增可操作的原生水平捲動條，保留下方捲動條；上、下都能移動整張矩陣，雙向同步，捲動範圍與終點一致，可看到 12 月及點位趨勢图。
3. **長表可用性**：上方 bar 在矩陣範圍內垂直捲動時固定於視窗上緣，避免必須到表尾才能左右移動；不能遮住篩選操作或表格內容。原生 bar 可聚焦，以左右方向鍵操作，具簡短可讀標籤。
4. **尺寸與篩選**：視窗縮放、篩選後重新載入，兩條 bar 仍同步且尺寸正確；表格沒有超寬內容時不顯示無意義的額外 bar。空資料頁不報錯，列印不出現額外 bar。
5. **原有功能**：月格明細連結、C01–C06 一廠分類、Alarm 黃／Action 紅與括號 CFU 趨勢維持既有已驗收行為。此工單不更動解析器、資料庫模型、匯入規則、數據或核對狀態；不重解析、不寫入正式資料。
6. **實際啟用**：工程自查後可由 Luna 使用既有本機服務啟停方式啟用本次頁面修改，提交可核對的桌面／窄視窗及捲動操作證據，供 PM 在正式頁面獨立驗收。這是已授權的可回復介面修改，不需再詢問使用者。
7. **交付与備份**：提交短篇 `docs/acceptance/EM-006-results.md`，只寫實際驗證結果，工程自查不可冒稱 PM 已通過。PM 驗收後正常提交並 push 既有 `codex/em-mvp-spec` 分支至 `JackTzeng/Environmental_Monitoring_Domain_Data_Model`，交 SHA。只含程式、工單與驗收文件，不含資料庫、原始報告、來源副本、session.key 或執行紀錄。
